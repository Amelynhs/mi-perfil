## Cómo correr el proyecto

1. Clona el repositorio y entra a la carpeta:
```bash
   git clone https://github.com/Amelynhs/mi-perfil.git
   cd mi-perfil
```

2. Instala las dependencias con:
```bash
   npm install
```

3. Levanta el proyecto con:
```bash
   npx expo start --lan --clear
```
Ten en cuenta que tienes que estar conectado a la misma red.

4. Te va a salir un código QR en la terminal. Abre la app Expo Go en tu celular y escanéalo.

5. Espera unos segundos y la app se abre solita en tu teléfono, mostrando la tarjeta de perfil.
